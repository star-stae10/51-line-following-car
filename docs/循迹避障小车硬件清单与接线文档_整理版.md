**关键点：**

- 7.4V 经 L298N 内部压降后，输出给电机约 **5.5V~6V**，正好匹配 TT 马达额定 6V。

- **5V 来自 L298N① 的板载稳压（78M05）**：7.4V 输入、板载 5V 按键按下后，L298N① 的 5V 端子输出 5V，直接给单片机 / 传感器供电，不再需要单独的降压模块。**只用一块模块的 5V 输出**，L298N② 的 5V 端子必须空置——两块同时引出会让两个 78M05 输出对顶，可能损坏。

- **共地**：电池负极、两块 L298N 的 GND、单片机 GND、传感器 GND，全部连通。

- **电源噪声**：单片机的 5V 现在和电机共用同一块模块，电机启停 / 换向会在 7.4V 母线上产生波动，可能干扰单片机（表现为偶发复位、跑飞）。建议在单片机电源脚附近并一个 100µF 电解 + 0.1µF 陶瓷电容，电机线尽量远离单片机电源线。

**2. L298N 接线（两块模块，每块驱动 2 个轮子）**

> 一块 L298N 只有 2 路 H 桥，最多驱动 2 个轮子；每驱动一个轮子要占用 2 个逻辑输入引脚（一路 H 桥用一对 IN：IN1/IN2 或 IN3/IN4）。四个轮子各自独立驱动，所以要用 2 块 L298N、共 8 个 IO 口。这里按**左 / 右**分组：**模块①带左侧两轮（左前、左后），逻辑输入接 P2 口（P2.0–P2.3）；模块②带右侧两轮（右前、右后），逻辑输入接 P3 口（P3.4–P3.7）**。两块模块的 12V 端子、GND 都接到同一路电池上；5V 由模块①的板载稳压输出给单片机 / 传感器，模块②的 5V 端子空置（只用板载稳压给自身逻辑供电）。P2 / P3 口都是准双向 IO、内部带上拉，可直接驱动 L298N 的逻辑输入；本设计不扩展片外存储器，P2 不会被当作高 8 位地址总线，P3 的 WR / RD（P3.6 / P3.7）也当普通 IO 用。P1.4–P1.7 用作 PWM 调速（见 三.5），P1.0–P1.3 空闲。

**电机接法**：每个轮子的两根线单独占一路输出（左后 → 模块① OUT1/OUT2，左前 → 模块① OUT3/OUT4，右前 → 模块② OUT1/OUT2，右后 → 模块② OUT3/OUT4），**不再把同一侧的两个电机并联**。电机转不转、往哪边转，取决于这一路两个 OUT 之间的电位差，也就是由对应的两个 IN 共同决定：两个 IN 一个高一个低才转，两个都高（刹车）或两个都低（制动）都不转（详见《循迹小车主要驱动模块参考资料》L298N 章 6.（1））。

| ⚠ **堵转电流**：L298N 单通道额定 2A，这里一路输出驱动 1 个 TT 马达。正常行驶没问题，但卡住 / 顶墙时堵转电流可能接近甚至超过 2A，容易触发过热保护。代码里避免长时间堵转——例如避障失败时不要持续满速顶墙，检测到堵转应退回重试。 |

**3. 红外循迹模块（TCRT5000 蓝板）**

| **模块引脚** |      **连接对象**      |
|--------------|:----------------------:|
| VCC          |       单片机 5V        |
| GND          |         总 GND         |
| OUT          | P2.4（左）/ P2.5（右） |

**输出逻辑（按本模块实测极性）**：黑线 → OUT 输出高电平 1；白底 → OUT 输出低电平 0。

**单路输出**：该模块只有一路数字输出（丝印 OUT），输出 0V / 5V 两种电平；没有 AO 模拟输出，也没有 DO 脚，三针即 VCC / GND / OUT。

**接线注意**：上表的行序（VCC / GND / OUT）只是罗列，不代表实物上的引脚排列顺序；实物三针的丝印顺序请照模块本身确认后再插。

**安装间距（决定循迹表能否成立）**：两个探头装在车头、横向排开，**中心距必须 ≤ 黑线宽度**。第四章的循迹表是按「正常行驶时黑线同时压住两个探头（都读 1）」推出来的；如果探头间距大于黑线宽度，正常状态下两个探头会分别落在黑线两侧的白底上，输出恒为 0/1 或 1/0，车就会一直修正、走不直。举例：黑线宽 2cm 时，两探头中心距装 1.5cm 左右。装好后先在直道上用手推车验证一次——车骑在黑线正中时，两个 OUT 应该同时为 1。

| ⚠ **极性需实测确认**：这个极性因模块批次而异，市面上相当一部分 TCRT5000 蓝板是**相反**的。写循迹代码前，先把车放到黑线上，用万用表或串口打印测一次 OUT 的实际电平。第四章的循迹判断表是按本极性推导的，若实测相反，0 / 1 需全部对调。 |
|----|

**4. 超声波模块（HC-SR04）**

| **模块引脚** | **连接对象** |
|--------------|:------------:|
| VCC          |  单片机 5V   |
| GND          |    总 GND    |
| Trig         |     P3.3     |

**注意**：Echo 输出为 5V 电平，51 单片机可直接读取，无需分压。

**5. PWM 调速（已启用）**

已经拔掉两块 L298N 的 ENA / ENB 跳线帽，四个使能脚分别接 P1.6（L298N① ENA，左后轮）、P1.7（L298N① ENB，左前轮）、P1.5（L298N② ENA，右前轮）、P1.4（L298N② ENB，右后轮）。

4 路独立 PWM：当前代码让同一侧的前后轮使用相同占空比，所以左侧两轮同速、右侧两轮同速；4 路分开接线保留了以后单独微调每个轮子的可能。

**PWM 实现**：Timer1 方式 2（8 位自动重装，TH1 = 72）产生约 5kHz 的中断，在中断里做 16 级（4 位）软件 PWM，实际 PWM 频率约 300Hz，占空比分辨率 1/16（6.25%）。受 8051 处理能力限制，频率低于通用推荐的 1~5kHz，但对 TT 马达足够，且比原来的 25Hz 方案平滑得多。Timer0 仍用于超声波计时和延时。

| ⚠ **跳线帽与 P1 不能同时接**：跳线帽把使能脚硬接到 5V，若同时又让 P1 输出，就是 IO 口与电源对顶，可能烧 IO。现在必须拔掉跳线帽，由 P1.4–P1.7 输出 PWM。 |
|----|

**P1.4–P1.7 用作 PWM，P1.0–P1.3 仍空闲**：8 个方向脚分占 P2（模块①）和 P3（模块②），PWM 只占 P1 的高 4 位。接线时不要再用 P1.4–P1.7 接别的东西。

**定时器是另一套资源**：PWM 必须用定时器中断（STC89C52RC 没有硬件 PWM），占用的是单片机内部定时器，**不占外部引脚**。本程序用 T1 产生 PWM，T0 用于超声波计时和延时。注意 P3.2 / P3.3 是 INT0 / INT1（现作超声波 Echo / Trig）、P3.4 / P3.5 是 T0 / T1（现作电机方向输出），都有复用功能，这里按普通 IO 用，代码里不要开对应的外部中断或外部计数即可。

**标定提醒**：降低 CRUISE_DUTY 会改变车速，避障动作的 15cm 停车距离必须重新标定。

**四、软件队友需知的控制逻辑**

------------------------------------------------------------------------

**1. 电机控制真值表（以左后轮为例）**

| **IN1** | **IN2** | **左后轮状态** |
|---------|:-------:|:--------------:|
| 1       |    0    |  正转（前进）  |
| 0       |    1    |  反转（后退）  |
| 0       |    0    |      停止      |
| 1       |    1    |      刹车      |

四路输出都按同一张表判断：左后轮看模块①的 IN1 / IN2，左前轮看模块①的 IN3 / IN4，右前轮看模块②的 IN1 / IN2，右后轮看模块②的 IN3 / IN4。四路互相独立，可以分别给方向；循迹 / 避障时通常让左侧两轮（左前 = P2.1/P2.0、左后 = P2.3/P2.2）同速、右侧两轮（右前 = P3.7/P3.6、右后 = P3.5/P3.4）同速，靠左右差速转向。

*注：上表 0/0 一行写成「停止」，但 IN1=IN2=0 且使能为高时，该路两个 OUT 同为低电平、电机两端被低阻通路短接，实际是短接制动；使能为低（PWM 占空比为 0）时输出高阻，电机才是滑行。*

**2. 循迹判断逻辑**

| **左红外 (OUT)** | **右红外 (OUT)** |      **判断**       |    **动作**     |
|------------------|:----------------:|:-------------------:|:---------------:|
| 1               |        1        |   两探头都在黑线上   |      直行       |
| 1               |        0        | 右探头偏白（车偏右） |    左转修正     |
| 0               |        1        | 左探头偏白（车偏左） |    右转修正     |
| 0               |        0        |      完全脱线        | 停车 / 原地找线 |

*注：本表基于「黑线 = 1」的极性（见 三.3），并要求两个探头间距 ≤ 黑线宽度（见 三.3「安装间距」），即正常时黑线能同时压住两个探头。实测极性若相反，把 0 与 1 对调即可。*

**推导**：探头压在黑线上输出 1，压在白底上输出 0。右探头读 0，说明它已经离开黑线、黑线相对车往左挪了，也就是车实际**偏右**，要让车向左靠回黑线，所以**左转修正**；左探头读 0 同理，车**偏左**，**右转修正**。

**3. 避障逻辑建议**

- HC-SR04 测得距离 \< 20cm 时，暂停循迹，执行避障（转向或后退）；避障动作中在 15cm 处停车（见 三.5）。

- 障碍物移开后，恢复循迹。

- 建议写成状态机：STATE_LINE_FOLLOW / STATE_AVOID。

**4. HC-SR04 测距时序**

1.  Trig 拉低至少 2us。

2.  Trig 拉高 10us，然后拉低。

3.  等待 Echo 变高，记录高电平持续时间 t（us）。

4.  距离 = t × 340 / 2 / 10000（单位 cm）。

**五、避坑清单（通电前必查）**

------------------------------------------------------------------------

1.  **共地**：所有模块 GND 必须连通，否则电机不受控。

2.  **5V 供电**：接单片机前用万用表确认 L298N① 的 5V 端子输出约 5.0V；确认 L298N② 的 5V 端子没有接线（避免两个 78M05 对顶）。

3.  **电池极性**：红线正、黑线负，接反必烧。

4.  **L298N 5V 按键**：两块模块的板载 5V 按键都要保持按下状态，指示灯亮。

5.  **ENA/ENB 跳线帽**：两块 L298N 的 ENA/ENB 跳线帽必须拔掉，使能脚改由 P1.6 / P1.7 / P1.5 / P1.4 的 PWM 驱动。跳线帽把使能脚硬接 5V，若同时让 P1 输出，就是 IO 与电源对顶，可能烧 IO。

6.  **红外模块离地高度与间距**：离地 1~2cm，太高识别不到黑线；两个探头中心距要 ≤ 黑线宽度，否则正常行驶时黑线压不住两个探头，车会一直修正（见 三.3「安装间距」）。

7.  **超声波盲区**：2cm；建议触发阈值取 20cm 左右（见 四.3），最低不要低于 15cm。

8.  **电池低压保护**：小车明显变慢立即充电，勿过放。

9.  **P3 口复用**：P3.2 / P3.3 是 INT0 / INT1，现在作超声波 Echo / Trig，代码里不要开 EX0 / EX1；P3.4–P3.7 是 T0 / T1 / WR / RD，现在作模块② 的电机方向输出，不要把 T0 / T1 配成外部计数。
